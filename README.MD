## Desafío 4 - Inmobiliaria ADL

Este es el sitio web de la Inmobiliaria ADL, que ofrece propiedades en venta y arriendo.

Este Proyecto fue desarrollado para DesafioLatam en el modulo de JS, implementando arreglos, odjetos y manipulación del DOM con JavaScript.

## Descripción

Esta WEB se constituye con 3 paginas html:

- index.html — Como página principal. 
- Propiedades_venta.html - Muestra las propiedades en venta.
- Propiedades_arriendo.html — Muestra las propiedades en arriendo.
